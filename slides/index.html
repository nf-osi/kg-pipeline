The Problem

Portal Limitations

  • NF portal data locked in flat Synapse tables
  • Cross-entity queries require manual joins
  • No semantic relationships between resources
  • Complex questions frustrate researchers

KG Pipeline Solution

  • Build a knowledge graph from portal data
  • Map labels to ontology IRIs (SSSOM)
  • Enable SPARQL queries over linked data
  • Power an AI agent for natural-language QA
